# osu!taiko Mapping Tools

A Windows desktop tool for osu!taiko mappers, featuring: metadata manager, volume/kiai copier, map cleaner, offset shifter, BG settings, video settings, and more!


## Notice!

Windows may prevent the app from opening because it is not digitally signed. If this warning appears, click **“Run anyway”** to launch the app.

If you have concerns about malware or security, the app’s source code is publicly available for review.
